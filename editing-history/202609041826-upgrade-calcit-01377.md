# Upgrade calcit-ir-viewer to Calcit 0.13.77

- Raise the compiler baseline from 0.13.33 to 0.13.77 and pin the JavaScript runtime package to the exact matching version.
- Resolve Calcit modules strictly and install JavaScript dependencies immutably before verifying the exact linked toolchain.
- Pin the existing setup-calcit 1.3.0 action to its immutable commit and restrict the workflow token to read-only repository contents.
- Keep deployment push-only while preserving viewer behavior, application version 0.0.2, and the existing static analysis gates.

## Blocked validation

- Yarn 4.12.0 immutable installation and exact Calcit/procs 0.13.77 toolchain verification pass.
- `caps --strict --ci` rejects three pre-existing dependency-version divergences for Respo UI, Respo core, and Lilac.
- The root Snapshot needs no 0.13.51 migration changes and is canonicalized by 0.13.77, but `--check-only` stops at published `Respo/respo.calcit@0.16.83`: `respo.core/defcomp` still has the legacy whole-`Dynamic` macro schema rejected by 0.13.77.
- No pull request should be opened until a compatible published Respo dependency graph is available and the complete static-analysis/JS/Vite workflow passes.
